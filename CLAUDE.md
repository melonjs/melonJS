# melonJS

@AGENTS.md

## For Claude Code

In a checkout of this repository the melonJS skills are files, not installed
skills: nothing loads them for you. Open
`packages/melonjs/skills/melonjs/SKILL.md` yourself before writing an example,
a plugin, a test or an engine feature, and follow it to the skill for the task.
(Games that use melonJS get the same guides as installed skills, through
`/plugin marketplace add melonjs/melonJS`.)
